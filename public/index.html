STEP 2 — 내 Chat ID 등록
방금 만든 봇에게 텔레그램에서 /start 전송 → 봇이 Chat ID를 알려줌 → 아래에 입력
STEP 3 — 감시할 채널에 봇 초대

텔레그램 채널 · 그룹에 봇을 관리자로 초대하면

📋 신고 전 준비할 것

  • 스크린샷 + URL 저장신고 전 반드시 증거를 보존하세요. 플랫폼이 먼저 삭제하면 증거가 사라집니다.
  • Unveil 분석 결과 PDF 저장위 "PDF 문서 생성" 버튼으로 만든 분석 리포트를 보관하세요. 수사기관 제출용 참고자료로 활용됩니다.
  • 업로드 날짜·시각 기록콘텐츠가 언제 올라왔는지 기록해두세요. 정확하지 않아도 대략적인 시기라도 중요합니다.
  • 가해자 정보 (알고 있다면)계정명, 닉네임, 연락처 등 가능한 정보를 정리해두세요.

🚔 경찰청 ECRM 온라인 신고 방법

1
사이트 접속

ecrm.police.go.kr 접속 → "사이버범죄 신고하기" 클릭

2
범죄 유형 선택

"사이버 성폭력" → "허위영상물(딥페이크)" 선택

3
내용 작성

발견 일시, 플랫폼명, URL, 피해 경위 작성. Unveil 분석 PDF를 첨부하면 신고 신뢰도가 높아집니다.

4
접수 확인

신고 후 접수번호를 저장하세요. 이후 진행 상황 조회에 필요합니다.
